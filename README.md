# ルーンスケープを日本語でプレイ！(beta)

連絡先/contact
https://discord.com/invite/T4wNWu6Uhk

このプラグインの機能はまとめると二つです。
1. ゲーム内テキストを日本語で表示
2. 日本語でチャット

ゲーム内テキストは簡易的な翻訳、もしくはDeepLを使った翻訳が可能です。
簡易的な翻訳は単純に単語ごとに和訳するだけであり、文法は全く考慮しないのでDeepLを使うことをおすすめします。

### 大部分の翻訳は未完成です
必要な場合は設定から不要な翻訳から☑を外してください。
プラグイン自体をオフにすると再度オンにするときに時間がかかってしまいます。

## プラグイン使い方
設定画面に行くと、様々な設定が行えます。
1. APIの設定
   * DeepLのAPIを使う際の設定ができます。
2. ゲーム内テキストの翻訳設定
    * NPCとの会話
    * ゲーム情報（チャット欄に表示される、プレイヤー発言以外の文言）
    * マウス周辺（マウスを置いた際や右クリックでメニューを開いた際に表示される文言）
    * 画面やボタンなど
3. 発言の翻訳設定
    * ローマ字変換：ローマ字で打つとそれを変換して日本語として表示できます
    * 簡易翻訳：英語を単語単位で和訳します（なので語順はそのままの変な翻訳）
    * DeepL翻訳：英語をDeepLを使って翻訳します、簡易翻訳よりはるかに良いけどたまに仕方ない間違いがある
    * そのまま表示：入力されたまま表示する
4. 特定プレイヤーの翻訳設定
    * 特定のプレイヤーごとの翻訳設定が可能です
    * 使う場合は書いてある日本語を全て消してから、指定したいプレイヤー名を入力する
    * 複数名いる場合は半角のカンマ「,」で区切る
    * 上記「3.」の設定よりこっちが優先的に反映されます
5. 翻訳データ提供
    * Discord からWebhook URLというものを配布しているので、それを入力して翻訳の質向上にご協力ください。
    * ゲーム内でプレイヤーが目にするアイテム名などの中から未確認のものを専用Discordチャンネルに報告します。
    * 決してチャット内容などはその対象になりませんが、アイテム名等とはいえ勝手にデータを収集するのはプライバシー的にどうかと思ったのでデフォルトでは送信しないようにしてあります。

## DeepL翻訳の詳細

DeepLは使用開始日から一カ月間は500,000「文字」まで無料で翻訳できます。勝手にお金を使ってそれ以上翻訳されることはない（らしい）です。
念のため当プラグインでも翻訳文字数を把握し、上限より少し前でAPIを使った翻訳はしないようにしてあります。

以下が当プラグインでDeepLを使う手順になります。

1. DeepLのアカウントを作成
   * クレジットカード情報が必要になります
2. アカウント作成後、右上の自分のアカウントの丸いアイコンをクリック
3. 「アカウント」をクリック
4. 「APIキー」をクリック
5. 有効なAPIキーを、四角が２つ重なっているアイコンをクリックしてコピー
6. 当ブラグインの設定画面を開く
   * RuneLiteの右側にアイコンが並んでいます
   * その一番上の工具アイコンをクリック
   * 上に工具アイコン、人のアイコン、プラグのアイコンが表示されますが、工具アイコンをクリック
   * 検索バーで「japanese」と入力して検索
   * 「Japanese」と書いてあるやつの歯車アイコンをクリック
   * 上の方の「DeepLのAPIキー」の入力バーにステップ「5.」でコピーしたキーを貼り付ける
   * 「DeepLを使用」にチェックを入れる
   * 翻訳文字数を常に表示する場合は「DeepLの翻訳文字数を表示」にチェックを入れる
   * プラグイン一覧に戻るアイコン
7. もしDeepLの使用を停止したい場合は貼り付けたキーを消すか、「DeepLを使用」のチェックを外しましょう
